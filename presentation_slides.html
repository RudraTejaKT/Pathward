MAJOR PROJECT

OUR MAJOR PROJECT: BACKLOX

CAREER GUIDANCE PLATFORM FOR 12TH-PASS STUDENTS — A unified roadmap & mentoring web application empowering students with curated guidance across engineering, medicine, and technology streams.

THE PROBLEM
High school students completing 12th grade face immense confusion regarding career pathways, branch specializations, essential semester skills, and real-world IT industry role requirements.
OUR SOLUTION
BACKLOX — An interactive, full-stack career platform designed to help students explore post-12th streams, compare branch curriculum, follow semester roadmaps, build project portfolios, and prepare for high-demand jobs.
WHAT WE BUILT
A high-performance SPA featuring branch roadmaps (CSE, IT, AI/DS, ECE, Mech, Civil), student dashboards, project recommendations, AI-assisted career advisory, and a secure Razorpay Pro unlock.
ICT Academy • CIT
BACKLOX ARCHITECTURE

BACKLOX: TECHNOLOGY STACK & DATABASES

A robust, scalable full-stack ecosystem combining modern reactive frontend interfaces, dual-database persistence, automated testing, and cloud infrastructure.

FRONTEND React 19 & Vite 8
SPA architecture, React Router v7, Context API state management, responsive dark-mode Glassmorphism CSS3, and Oxlint code quality.
BACKEND Node.js & Express 5
Modular RESTful API routes, JWT bearer authentication, Bcrypt.js password security, Multer asset handling, and custom RAG AI query engine.
DATABASES SQLite & PostgreSQL (Supabase)
Dual data storage: better-sqlite3 for fast local transactional persistence + Supabase Cloud SQL with Row-Level Security (RLS) & serverless JSON fallback.
PAYMENTS & DEVOPS Razorpay & AWS Cloud
Razorpay HMAC-SHA256 signature verification, AWS S3/CloudFront CDN/EC2 deployment, Vercel edge routing, and Docker containerization.
